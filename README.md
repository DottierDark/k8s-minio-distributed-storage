# 🚀 k8s-minio-distributed-storage

A highly available, distributed object storage solution using **Kubernetes and MinIO**.

## 📌 Overview

This project sets up a **Kubernetes-based distributed storage system** using MinIO, providing:

- **High availability** through replication across multiple nodes.
- **Persistent storage** with Kubernetes Persistent Volumes (PVs).
- **Fault tolerance** using MinIO’s **Erasure Coding**.
- **Scalability** to handle large datasets in a cloud-native environment.

## 🔹 Features

✅ **Kubernetes-based storage solution**
✅ **MinIO as the object storage engine**
✅ **Highly available storage system**
✅ **Persistent storage with Kubernetes PVs**
✅ **Fault tolerance with Erasure Coding**
✅ **Scalable storage solution**

## 🛠️ Tech Stack

- **Kubernetes (K3d)**
- **Helm (Package Manager)**
- **MinIO (Object Storage)**
- **MinIO Client (`mc`)**
- **Docker (Containerization)**
